VERCEL SETUP

1. Put your real photos in assets/ named:
photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg

2. Put your song in assets/ as song.mp3.
3. Change the song title in index.html if you want.
4. Upload this folder to GitHub and import the repository into Vercel.
5. Vercel preset: Other / no framework.
6. Deploy.

Only use music you have permission to use.
